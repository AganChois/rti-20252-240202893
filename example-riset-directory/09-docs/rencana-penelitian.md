# Rencana Penelitian: Evaluasi Kualitas Sistem Pemasaran Pertanian dengan ISO 25010

## 1. Ringkasan

| Item | Keterangan |
|---|---|
| Judul | Peningkatan Kualitas Sistem Pemasaran Pertanian Berbasis Web Menggunakan Metode Prototyping Berdasarkan Standar Kualitas ISO 25010 |
| Target Publikasi | Jurnal Nasional Terakreditasi (Sinta 3-4) |
| Stack | Laravel, Vue.js, MySQL, Python (Pandas, SciPy) untuk analisis |
| Masalah | Sistem pemasaran pertanian yang ada seringkali dikembangkan tanpa evaluasi kualitas yang terstandar, menyebabkan masalah *usability* dan adopsi oleh pengguna. |
| Solusi | Menerapkan metode pengembangan prototyping untuk membangun sebuah sistem dan mengevaluasi kualitasnya secara kuantitatif menggunakan standar ISO 25010. |

---

## 2. Alur Kerja (Roadmap)

Penelitian ini dibagi menjadi beberapa tahap yang terstruktur. Setiap tahap memiliki dokumen perencanaannya sendiri untuk detail yang lebih lengkap.

- [x] **Tahap 1** — Perancangan Eksperimen dan Proposal
  - **Tujuan:** Mendefinisikan masalah, RQ, hipotesis, dan desain eksperimen.
  - **Referensi:** `ws-01` s.d. `ws-08`.
  - **Output:** `01-proposal/proposal-penelitian.md`

- [x] **Tahap 2** — Desain Arsitektur dan Implementasi Sistem
  - **Tujuan:** Merancang arsitektur sistem 3-Tier dan mengimplementasikan prototipe fungsional.
  - **Referensi:** `ws-09-implementation.md`.
  - **Output:** `03-teori/arsitektur-dan-skema.md`, `05-kode/app/`

- [x] **Tahap 3** — Pengumpulan dan Validasi Data
  - **Tujuan:** Melaksanakan pengujian dengan 24 responden, mengumpulkan data kuesioner, dan memvalidasi integritas data.
  - **Referensi:** `ws-10-execution-data.md`, `ws-11-data-validation.md`.
  - **Output:** `04-data/hasil-kuesioner-mentah.csv`

- [x] **Tahap 4** — Analisis Data
  - **Tujuan:** Menganalisis data menggunakan statistik deskriptif dan uji hipotesis untuk menjawab RQ.
  - **Referensi:** `ws-12` s.d. `ws-14`.
  - **Output:** `05-kode/analysis/`, `06-output/`

- [x] **Tahap 5** — Penulisan Naskah dan Laporan
  - **Tujuan:** Menyusun hasil penelitian ke dalam format naskah ilmiah (IMRAD) dan laporan akhir.
  - **Referensi:** `ws-15-scientific-writing.md`.
  - **Output:** `07-manuskrip/`, `08-laporan/`
